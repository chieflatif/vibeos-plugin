# Proportionate engineering review and routing

The user wants efficient engineering, not another orchestration framework. Reuse
the current companion and profile installer. Keep local intake default-off and
leave JEV and Foundry experiments separate.

1. Codex generation allows task-sized selection among runtime-exposed GPT models,
   including Luna. No Claude role alias fixes a GPT model. Parent ownership stays
   unchanged and deterministic work need not be delegated.
2. Enabled independent-review closure cannot skip because its target or evidence
   is absent. Valid structured evidence replaces redundant report-prose checks.
3. Claude remains the preferred independent provider. Only an operational failure
   plus explicit recorded user authorization permits the supported fresh-context
   same-implementing-model route. No automatic fallback, self-approval or invented
   observed-model/provider identity. Required tests and material findings remain.
4. Critical/high findings and unmet acceptance requirements block. Minor advice
   has explicit dispositions. New local blockers retain stable IDs and stay in
   targeted verification unless prior coverage is materially invalid. Existing
   version-1 receipts keep their old semantics.
5. Exact reviewed bytes, candidate commit/tree, acceptance and evidence remain
   bound. Unrelated work and future execution limits must not invalidate v2
   review; module disable or changed effective review requirements must not pass.
   Publication validation binds the exact release tree.
6. Companion review replaces overlapping generic fanout. Add a specialist only
   for a named gap. The agent prepares internal records from the existing change
   and test evidence; the user is not required to operate manifests or commands.
7. Default-off and existing profile preservation behavior remain. Mock-provider
   tests are not real provider proof, and source completion is not project adoption.

Prove normal, correction, provider-unavailable, approved-fallback and refusal
paths in isolated test fixtures; run the existing regression suite. A real
first-party independent source review is required before release. No real fallback
may be run for this candidate without actual user authorization.
